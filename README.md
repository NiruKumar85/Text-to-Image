## 📌 About the Project

**AI Text-to-Image Generator** is a web-based application that allows users to **generate images from text prompts** using Artificial Intelligence.

Simply type a description like  
> *"fish under water"*  
and the AI instantly creates a visually appealing image.

---

## 🚀 Features

✨ Generate images from text prompts  
🧠 AI-powered image generation  
🎨 Clean & modern UI  
⬇ Download generated images  
🔄 Reset and generate again  
⚡ Fast and responsive

## 🖥 How It Works

1. Enter a text prompt (e.g. *"fish under water"*)
2. Click **Generate Image**
3. AI processes the prompt
4. Image is displayed on the screen
5. Download or reset as needed
